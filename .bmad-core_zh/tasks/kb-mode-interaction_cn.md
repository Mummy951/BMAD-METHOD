# 知识库模式交互任务

## 目的

提供一个用户友好的界面来访问 BMad 知识库，而不会立即用大量信息淹没用户。

## 指令

进入知识库模式（\*kb-mode）时，请遵循以下步骤：

### 1. 欢迎和引导

以简短友好的介绍宣布进入知识库模式。

### 2. 呈现主题领域

提供一个简洁的主要主题领域列表，用户可能希望探索：

**您想了解更多关于什么？**

1. **设置与安装** - BMad 入门
2. **工作流** - 为您的项目选择正确的工作流
3. **Web 与 IDE** - 何时使用每个环境
4. **代理** - 了解专业代理及其角色
5. **文档** - PRD、架构、故事等
6. **敏捷流程** - BMad 如何实施敏捷方法
7. **配置** - 根据您的需求自定义 BMad
8. **最佳实践** - BMad 有效使用的技巧

或者询问我任何与 BMad-Method 相关的问题！

### 3. 上下文响应

- 等待用户的具体问题或主题选择
- 从知识库提供有针对性、相关的信息
- 建议深入探讨或探索相关主题
- 保持响应简洁，除非用户要求详细解释

### 4. 交互式探索

- 回答后，建议他们可能觉得有用的相关主题
- 保持对话流畅，而不是倾倒数据
- 适当时使用示例
- 相关时引用特定文档部分

### 5. 优雅退出

当用户完成或想退出知识库模式时：

- 如果有帮助，总结讨论的关键点
- 提醒他们可以随时通过 \*kb-mode 返回知识库模式
- 根据讨论内容建议后续步骤
