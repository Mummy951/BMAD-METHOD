# 增强型开发工作流

这是一个简单的分步指南，可帮助您使用 BMad 方法高效管理开发工作流。有关此处未涵盖的任何场景，请参阅**[<ins>用户指南</ins>](user-guide.md)**。

## 创建新分支

1. **启动新分支**

## 故事创建 (Scrum Master)

1. **开始新的聊天/对话**
2. **加载 SM 代理**
3. **执行**：`*draft` (运行 create-next-story 任务)
4. **审查生成的报告**在 `docs/stories/` 中
5. **更新状态**：从“草稿”更改为“已批准”

## 故事实施 (开发人员)

1. **开始新的聊天/对话**
2. **加载 Dev 代理**
3. **执行**：`*develop-story {selected-story}` (运行 execute-checklist 任务)
4. **审查生成的报告**在 `{selected-story}` 中

## 故事审查 (质量保证)

1. **开始新的聊天/对话**
2. **加载 QA 代理**
3. **执行**：`*review {selected-story}` (运行 review-story 任务)
4. **审查生成的报告**在 `{selected-story}` 中

## 提交更改并推送

1. **提交更改**
2. **推送到远程**

## 重复直到完成

- **SM**：创建下一个故事 → 审查 → 批准
- **Dev**：实施故事 → 完成 → 标记为可审查
- **QA**：审查故事 → 标记为完成
- **Commit**：所有更改
- **Push**：到远程
- **Continue**：直到所有功能都已实施
