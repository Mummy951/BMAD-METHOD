## 分析案例
1. 使用扁平化命令生成xml文件：
``` shell
node ./tools/flattener/main.js --input ./tools --output ./帮助文档/tools-分析.md
```
2. 将tools-分析.md拖入聊天框中，然后其后输入：分析这个命令行工具的架构和实现模式

3. @/帮助文档/Mermaid语法说明文档.md @/帮助文档/tools-分析.md 帮我分析命令行工具代码中所有入口点，以及类之间的依赖关系， 生成mermaid类图分析报告，保存到./帮助文档/tools-类图分析报告.md

4. @/帮助文档/tools-类图分析报告.md 将每一个功能拆分成单独的流程图保存到tools功能流程图分析报告.md

5. 总结@/docs目录下所有文档的内容， 分析@/bmad-core 核心功能的目录结构、包含的功能、以及每个功能的依赖项，并根据依赖项绘制每个功能的业务流程图，最终保存到 ./帮助文档/业务流程分析报告.md  @/帮助文档/BMad\ Method\ 分析开源项目的步骤.md

6. @/docs 结合文档，从新优化下@/业务流程分析报告v3.md ，保存到业务流程分析报告v4，流程图需要在节点上补充相关的文件名，不能只有文字描述，每个业务流程 补充一个最佳实践教程，以便用户能快速上手使用，最佳实践教程需要补充详细具体的操作步骤，包括输入什么指令指令，一步一步教会用户实际如何使用
